# Modelo final

Substitua este texto pelo modelo de classes final em Mermaid.

O modelo deve conter, no mínimo: `Usuario`, `Recurso`, `Reserva`, `PeriodoReserva`, `AgendaReservas`, `ServicoReservas`, `IPoliticaReserva`, as políticas concretas implementadas, multiplicidades relevantes e a composição entre `Reserva` e `PeriodoReserva`.
